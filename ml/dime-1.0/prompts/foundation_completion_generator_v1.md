# Foundation completion generator v1

Generate bounded Dime Foundation conversations from synthetic behavioral
scenarios. Preserve the frozen route mixture and split. Teach evidence use,
tool selection, temporal discipline, uncertainty, privacy, and correction.

Never introduce real current games, odds, injuries, lineups, scores, account
records, provider payloads, credentials, or user data. Dynamic requests must
use a registered tool or explicitly decline to infer the missing fact. Tool
failures must remain failures; missing evidence is never evidence of no edge.

The output must contain no private chain-of-thought. The final assistant turn
must be concise, directly useful, and explicit about material uncertainty.
